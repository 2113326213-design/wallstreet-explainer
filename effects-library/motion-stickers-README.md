# 视频动态贴片素材

两个压缩包共提供 550 个透明背景动态 GIF，可在支持透明动态 GIF 的剪辑软件中作为叠加层使用。先下载并解压，再打开各包内的 HTML 页面预览和单独下载。

- `original-252-gif.zip`：252 个 GIF，分为箭头、强调圈、标题框、下划线、放射强调、柱状图和中文标题七类。这是 42 款设计的 6 色变体，480×270，约 1.2 秒循环，中文文字固定不可编辑。原创图形按 CC0 1.0 提供，文字使用 Noto Sans SC 字体，许可说明随包附带。
- `useanimations-298-gif.zip`：298 个线条动态图标，来自 [useAnimations](https://github.com/useAnimations/react-useanimations)，MIT 许可，包内保留作者版权和许可证；256×256，约 20 帧/秒。品牌标志还可能涉及商标权，不应暗示获得品牌授权。

将 GIF 放在画面上方并调整位置和大小。不同剪辑软件对 GIF 动画、透明度和循环的支持不同；若显示静态图或背景不透明，需要使用支持透明动态 GIF 的软件或转换格式。当前素材并未自动接入 wallstreet-explainer 的逐帧渲染流程，视频渲染时需按帧处理并单独检查。
