# 财经科技视频 · 专业制作素材包

面向 wallstreet-explainer 的一套可商用制作资源。解压后用 Chrome 或 Edge 打开 `开始使用.html`；模板可离线预览。此包是额外资源，不会自动安装到原 Skill 或剪辑软件。

## 包含什么

- **8 套可编辑图表动画**（`charts/`）：柱图、排名条形、折线、环形、核心数字、双项对比、时间线和流程图。输入标题、项目与数值，可导出 PNG 和无声 WebM，或用 `window.seek(t)` 接入已有逐帧渲染流程。示例数据为虚构内容，请替换并标注真实来源。限制详见该目录使用说明。
- **12 套文字与引用版式**（`editorial/`）：开场、章节、姓名条、引语、原文高亮、字幕、关键词、数据大字、对比、时间节点、事实卡片与结尾。可编辑文字，下载可供逐帧渲染的 HTML；带背景，不是透明视频。
- **世界地图和路线动画**（`maps/`）：基于 Natural Earth 的简化底图，输入 2–6 个地点及经纬度，导出 PNG 或无声 WebM，另支持逐帧渲染。示例路线是示意，边界、地名及其表达须依据使用场景和适用要求另行核查；底图不适合精确导航或权威边界表达。
- **三维素材**（`3d/`）：两个 1K glTF 模型（复古笔记本电脑和电路板）及两张 1K HDR 环境光，适合 Blender 场景使用，不是现成视频。模型是示意，不能冒充真实企业产品；使用前需自行检查实际渲染效果。
- **资源与制作指南**：提供实拍、数据、地图、3D、配音、调色等官方来源和制作检查清单。一些第三方资源只能用于项目，不能作为素材重新分发，因此本包只提供它们的入口与说明。

## 使用顺序

1. 双击打开 `开始使用.html`，选择相应预览页；推荐使用支持 WebGL、WebM 的新版 Chrome 或 Edge。
2. 替换示例文字、数字或地点；预览并导出所需格式。WebM 无音轨，需在剪辑软件里处理声音。
3. 图表和地图支持项目逐帧渲染。具体路径和 `window.seek(t)` 用法详见各目录的使用说明。
4. 阅读 `资源与制作指南.md`，核对事实来源、授权、混音、字幕和最终交付。
