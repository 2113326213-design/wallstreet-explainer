# 镜头怎么接

每个边界先回答“上一镜留下什么、下一镜要看什么、靠什么接”，再从下面挑一种走法。下面写的是机制和什么时候用；画面每条片现写。走法都只交接注意力，不带新信息，也不挪动配音和字幕的时间点。

## 动作的手感（全片统一）

- 缓动：入场和落定用 ease-out（`1-(1-x)^3`），来回移动用 ease-in-out。不回弹、不过冲。
- 时长：小元素 0.2–0.35 秒，换焦点或重新取景 0.4–0.6 秒，交叠转场 0.25–0.35 秒。
- **砸入**（大数字、新闻卡、logo）：0.22 秒内从 1.28 倍收到 1，模糊从 9px 收到 0，透明度在前一半时间里拉满。可以同时让画面轻震一下（8px，0.13 秒衰减到零），配一声撞击。
- 快速移动时加一点模糊（运动模糊的感觉），停下就清楚。
- 实拍和舞台都不做慢推慢漂。

## 走法

**带过：同一个对象跨镜头**
- 7250 亿：开头砸出 → 片名时退成背后的暗字 → 下一句回到画面上方 → 分出两条线 → 结尾立成红柱 → 被四家押注。
- 要求：身份、颜色、比例不变；在上一镜的末态里已经在，下一镜一开场就在。

**推近：画框变成下一镜**
- 例：“芯片”画框推满屏 → 和黄仁勋的镜头交叠 0.18 秒（他从 1.08 倍收到 1）→ “卖芯片的英伟达”。推近的是同一份东西，不换成一张相似的图。

**人 ↔ 圆盘：人物和他代表的节点互相变**
- 实拍缩成盘：用 `clip-path: circle()` 把全屏实拍从半径 1150 收到盘的半径，圆心同时挪到盘的位置（0.5 秒），盘在后半段淡入，盘里就是他的抠像。观众能直接看懂“这个人就是这个盘”。
- 反过来展开：先让上一个舞台往旁边让开，再从右边一个圆里展开下一个人（Altman）。
- 盘撑开成窗口：钱回到英伟达后，从盘的位置把黄仁勋的原声窗口撑开（大小、圆角、位置一起变），说完再缩回盘里。盘在屏幕上的位置要实测，镜头推近以后它不在原坐标。

**原文 → 图表：数从原文里出来**
- 路透原文刷黄“$280 billion by 2030” → 页面缩小上移、淡出 → 白底图表从下方升起，曲线画到 2030 年，-2780 亿落在末端。

**续，并且让位：上一张图缩到一边，新东西进来**
- “光是算力”：图表缩到左侧（约 0.52 倍），右侧落下机柜画框，8560 亿砸在框下面。两边一比，观众自己就看出“算力比亏损还大”。
- 做法：用“不画背景”的开关把上一镜的内容单独拿出来缩放，背景照常铺满，避免露出黑边或者变成屏幕套屏幕。

**证据小卡：从相关的地方弹出来，看完缩回去**
- “英伟达投钱给 OpenAI”：CNBC 的实拍从“投资”箭头旁边弹成一张白边小卡，背景压暗；读完缩回箭头，桌面没有离场。不要切成全屏打断这张关系图。

**推过镜头：换舞台时，上一镜的末帧冲过来**
- 上一镜最后一帧放大到 1.28 倍、模糊 12px、淡出（0.3 秒），盖在新一镜上。用在舞台换了、又没有对象可带的时候（比如图表 → 3D 桌面、桌面 → 柱状图）。
- 结尾 Meta 标志推过镜头接扎克伯格本人，用的是同一个机制，但放大中心对准那个标志，放大到 4 倍。

**分流：一个数分成几路**
- 7250 下面伸出两条线，落到“芯片”“数据中心”两个画框。线要画出来（描边动画），框跟在线后面落下。

**押注：开头的东西在结尾回来**
- 开头那四家公司的 logo，在“大家都在赌”时一个个落到红柱上（2×2）；“连扎克伯格自己都说”时只有 Meta 亮起，其余压暗。首尾呼应，不需要解释。

**开头钩子**（关键词快闪、一个数砸下来、反差并排、悬念循环……）：每条片选一种，见 `opening.md`。

## 别这样

- 每个切点都套一个特效。
- 为了“有变化”去换机位或者换背景。
- 连续硬切几次，每次都要观众重新找位置。
- 用闪白、飞纸、通用遮罩去盖一个没有理由的切换。
- 东西凭空出现：新东西要从它来的地方进场（箭头、上一个数、画框），或者经过一次清楚的换场。
