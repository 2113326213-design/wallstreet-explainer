# 实践中踩过的坑

示例片做了五个版本，下面是每一步暴露的问题和最后的改法。遇到新情况，先看这里有没有类似的。

## 风格和质感

| 问题 | 为什么不行 | 改法 |
|---|---|---|
| 背景用 AI 生成的电影感图（熔炉、赌场、神殿） | 一眼就假，显得廉价 | 舞台只用中性纹理；人物和事件用真实素材 |
| 文字用弹跳、打字机、闪白、扫光入场 | PPT 感，参考风格里根本没有这些 | 只用淡入、硬切，以及先快后慢的砸入 |
| 把实拍当背景，上面压标题和数字 | 同样廉价 | 实拍和图形舞台是两种镜头，轮流出现 |
| 用低清百科视频 | 画质一看就不行 | 换官方 1080p 宣传片和纪录片 |
| 实拍和舞台都加慢推慢漂 | 廉价 | 定机位；镜头只在换焦点时动 |
| 英文副标题、章节牌、来源小字 | 太多小字，看着累 | 一镜最多一个短的中文标签 |

## 素材和逻辑

| 问题 | 为什么不行 | 改法 |
|---|---|---|
| 念到公司名就切航拍 | 看不出是谁家的楼 | 身份要在画面里：脸、logo、写着名字的新闻标题 |
| 镜头之间硬切，素材只停零点几秒 | 前言不搭后语，前因后果看不出来 | 先写导演表，逐镜写“承接”一列；实拍至少停 1.5 秒左右 |
| 资金关系图中间插一段全屏新闻片 | 打断关系图 | 新闻做成小卡，从箭头旁弹出，读完缩回去 |
| 直接插 CEO 原声 | 观众不知道他是谁、为什么在这说 | 先加铺垫句，画面上也做交接 |
| 结尾放一段好看但和内容无关的航拍 | 跟论证没关系 | 结尾回到全片那个数字和开头那几家公司 |
| 收到修改意见后换了一种风格重做 | 偏离了已经认可的版本 | 在原版上逐镜改；改动多时先列清单确认 |

## 开头

| 问题 | 改法 |
|---|---|
| 没信息量的空镜开场 | 用关键词钉在中央的快闪，垫在第一句话下面 |
| 新闻卡随机乱叠 | 关键词固定在屏幕正中，周围的出处在换 |
| 旁白前空等两秒放快闪 | 缩到 0.3 秒就开口 |
| 搜索引擎拦截截图 | 用核实过的文字自己排效果图，不仿真实网站 |

## 声音

| 问题 | 原因 | 改法 |
|---|---|---|
| 语速时快时慢 | 每句前后带着 0.2–0.6 秒静音，再加上停顿 | 每句切掉首尾静音，停顿只由 gap 决定 |
| 语速听着急促 | 切掉静音后又拉了 1.1 倍 | 保持原速 |
| 配乐“怪” | 紧张滴答乐和放映机声 | 去掉，只留平稳的底乐和轻翻书声 |
| 原声里有“异响” | 句尾砍掉半个词；截进了一段数字静音 | 剪口按波形定 |
| 字幕和卡点全错 | 对齐脚本用文件名前三个字当键，b10b 覆盖了 b10 | 键用完整编号 |

## 工程

| 问题 | 改法 |
|---|---|
| 交出去的文件打不开（合成没写完） | 每个文件用 ffprobe 验证过再交 |
| 合成时 ffmpeg 卡死 | 在一个大滤镜图里同时读带画面的 mp4、图片和多条音轨会互相等待；音频先抽成 wav，字幕和音频分开合成 |
| yt-dlp 403 | `pip install -U yt-dlp` |
| edge-tts 403 | `pip install -U edge-tts` |
| 实拍黑屏或空框 | 新素材的帧数没登记 |
| 停住的画面露出下一个镜头 | 抽帧时出点压在了镜头切点上 |
| 荧光笔和文字对不齐 | 字体加载完以后再量、再截 |
