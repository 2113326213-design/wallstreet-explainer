# 示例：《AI到底有多烧钱》（77 秒）

这是一条片子从想法到成片的记录，用来学“怎么想”。**不要照着它的镜头顺序做新片**，新片的画面要从新片自己的文案里现想。

- `script.txt`：最终文案。原声部分不在里面，见下表“反应梗”和“扎克伯格”两行。
- `director.md`：导演表。重点看每一镜的“承接”一列：它接住了上一镜的什么。
- `frames_1fps.jpg`：成片每秒一帧。
- `CREDITS.md`：全部素材的出处。

## 论证主线

追一笔钱：
1. 四家一年砸 7250 亿。
2. 大头流向芯片和数据中心。
3. 卖芯片的英伟达成了全球市值第一；买算力的 OpenAI 估值高，但收入小，到 2030 年还要净亏 2780 亿。
4. OpenAI 的钱有一笔来自英伟达，钱在英伟达、OpenAI、甲骨文之间转了一圈。
5. 一年砸进去 7250 亿，收回来的差一大截。
6. 这一截就是赌注，连押注的人自己都知道可能白花。

## 每一段为什么这么拍

| 段 | 画面 | 为什么 |
|---|---|---|
| 开头 | “烧钱”快闪：关键词钉在中央，周围的出处每 5 帧换一张 | 视线有落点，一眼看出“全网都在说”；垫在第一句话下面，不空等 |
| 四家 | 每念一家，那家自己的资本开支新闻砸到最上面，然后排成四宫格 | 新闻标题里写着公司名和金额，身份自己说清，同时也是证据 |
| 7250 | 四张卡汇到中间，7250 亿砸出 | “加起来”这个动作被真的演出来了 |
| 钱花哪了 | 7250 回到上方，分出两条线到“芯片”“数据中心”两个画框 | 一个数分成两路；两样东西同时停在屏上，够时间看清 |
| 英伟达 | 芯片画框推满屏，接黄仁勋，他的画面再缩成英伟达圆盘 | 芯片 → 卖芯片的人 → 他代表的公司，三步是同一件事 |
| OpenAI | 英伟达舞台往左让开，Altman 从一个圆里展开，再缩成 OpenAI 圆盘；360 亿的小盘按面积比例画 | 和英伟达那段用同一种走法，观众已经学会了；面积比例让“才 360 亿”一眼可见 |
| 净烧 | 路透原文刷黄 → 图表升起，-2780 亿落在曲线末端 | 可能被质疑的数，先给原文出处 |
| 算力 | 图表缩到左边，右边机柜画框加 8560 亿 | 两个数并排，不用说出来就知道“算力比亏损还大” |
| 资金循环 | 3D 桌面上三个盘、三根管子；CNBC 新闻小卡从“投资”箭头旁弹出又缩回；一个亮点沿管子跑一圈 | 关系图一直在场；新闻条就是证据；“转了一圈”真的转了一圈 |
| 反应梗 | “难怪黄仁勋总爱说这句：”→ 从他的圆盘里撑开小窗：“买得越多，省得越多” | 先铺垫再放原声；从盘里撑开，观众知道这是谁 |
| 差一大截 | 7250 立成红柱，旁边矮柱打问号，括号标“差一大截” | 开头那个数回来了 |
| 赌 | 括号里的空白亮起；开头那四个 logo 落到红柱上；问号放大 | 首尾呼应：押注的就是开头那四家 |
| 扎克伯格 | “连扎克伯格自己都说：”→ Meta 亮起 → 推过镜头到他本人，三句原声 | 结尾落到一个判断：他们知道可能白花，还是要砸 |

## 版本演进（摔过的跤）

| 版本 | 问题 | 改法 |
|---|---|---|
| v1 | 全片 PPT 感：背景是 AI 生成图，文字全是特效入场 | 背景换成纯纹理，动画只留淡入和硬切 |
| v2 | 实拍上压字 | 实拍和图形舞台分开，轮流出现 |
| v3 | 低清百科素材，镜头慢推，开头是没有信息量的空镜 | 换官方高清片，定机位 |
| 冷开小样 | 换成了纪录片冷开，偏离风格；卡着公司名切航拍，看不出是谁家的 | 在原版上逐镜改；画面里要有身份 |
| v4 | 镜头之间不接；素材只停零点几秒；原声没铺垫；结尾航拍和内容无关；小字多 | 写导演表，逐镜写承接；加铺垫句；去掉小字 |
| v5 小样 | 新闻卡随机乱叠，视线没落点 | 改成关键词钉在中央的快闪 |
| v5 小样 2 | 旁白前空等 2 秒；紧张配乐怪；配音没切静音，节奏时长时短 | 空等缩到 0.3 秒；去掉紧张乐；配音切掉首尾静音 |
| v5 | 配音加速后听着急促；原声砍掉半个词，又截进了一段数字静音 | 配音改回原速，原声剪口按波形重定 |
