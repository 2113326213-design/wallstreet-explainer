# 品牌标志素材

`company-logos-473.zip` 包含 473 个品牌 SVG，包括公司、产品和服务标志；数量不等于 473 家公司。解压后打开“浏览标志.html”，可搜索、预览并单独下载。大多数为单色矢量图形，个别品牌为其他呈现方式。
