# 免费商用图标与 Emoji 素材库

将两个压缩包解压到同一目录，合并为 `visual-assets/` 文件夹后，打开其中的 `打开浏览素材.html`，可以按名称搜索、预览和下载 SVG。完整素材离线保存在 `icons/` 和 `emoji/`，不依赖第三方网站。可将 SVG 拖入支持 SVG 的设计、剪辑或演示工具；若软件不支持，请转换为 PNG 后使用。

- 图标：5844 个 SVG（线框和实心），来自 Tabler Icons 3.50.0，MIT。已排除文件名以 `brand-` 开头的品牌标志。来源：https://github.com/tabler/tabler-icons 。版权及 MIT 全文：`icons/LICENSE`。
- 表情：3145 个 SVG（flat 彩色样式，包含肤色等变体），来自 Microsoft Fluent Emoji，由 @fluentui-emoji/svg 2.2.0 分发。MIT。来源：https://github.com/microsoft/fluentui-emoji 和 https://github.com/MKAbuMattar/fluentui-emoji 。版权及 MIT 全文：`emoji/LICENSE-MICROSOFT.txt` 与 `emoji/LICENSE-PACKAGER.txt`。

许可证允许商用、修改与分享，分发副本时须保留对应版权声明和许可文本。图库的具体图像不保证已按使用量排序；包含的肤色、性别或其他变体按不同 SVG 文件计数。

若将素材用于 HTML，可直接用 `<img src="...svg">`；混入视频时按画面需要选择和缩放。部分 SVG 采用 currentColor，作为图片通常显示黑色，可以使用支持 SVG 编辑的软件改色。Skill 使用这些素材时，先查看本目录授权，按画面挑选，不要用图标代替真实人物、企业或新闻画面。
