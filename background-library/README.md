# 免费商用背景图

共 206 张 JPEG 图片，可用于视频、演示和设计：

- 56 张风景及城市照片，来自 Wikimedia Commons，通常为 1920 像素宽的缩小并转存版本。
- 114 张来自 Poly Haven 的实拍材质纹理，包括木材、石材、金属和砖等，均为 1024×1024 方形图片。
- 36 张本项目原创底图，1920×1080；这是 9 种设计、每种 4 个配色，并非 36 种完全不同的构图。

每张图片均以 CC0 1.0 提供，允许免费商用。各条原始来源、作者、分辨率等信息可在预览页或 `manifest.json` 查看。风景照片可能含建筑等内容，使用时请按实际场景核对可能存在的第三方权利。来源说明：[Poly Haven 授权](https://polyhaven.com/license)、[CC0](https://creativecommons.org/publicdomain/zero/1.0/)。

## 下载和预览

下载 `background-index.zip` 和全部 7 个 `background-images-01.zip` 至 `background-images-07.zip`。将它们解压到同一文件夹，再打开其中的“浏览背景.html”：可按类型或名称查找，预览后下载单张图片。全部图片都在压缩包内，离线可用；查看原始来源需要联网。若只下载部分图片包，浏览页会提示缺少未下载的图片。

照片比例和纹理的分辨率各不相同，放入 16:9 视频时可能需要裁切、铺满或缩放；1024×1024 纹理放大到全屏时清晰度会降低。
