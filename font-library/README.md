# 免费商用字体库

共 303 个不同字体家族，各提供一个实际字体文件与对应的 SIL Open Font License 1.1 授权文本：296 个英文字体和 7 个中文字体。字体均来自 Google Fonts 或 Noto 官方来源，允许用于商业项目；请保留各字体的原始授权文件。字体家族按名称去重，不把不同字重重复算作新字体。

## 下载与预览

- `latin-fonts-296.zip`：296 款英文字体。解压后打开“浏览字体.html”可输入英文和数字进行预览、搜索、下载和查看许可。每个家族只有一个版本，文件主要覆盖拉丁字母与数字，不适合作为中文字体使用；并非完整字重系列。
- `chinese-fonts-5.zip` 和 `chinese-noto-2.zip`：共 7 款中文字体；把两个压缩包解压到同一个文件夹（允许合并 `fonts` 文件夹），再打开“浏览中文字体.html”可预览七款。前者包含站酷快乐体、站酷小薇体、站酷庆科黄油体、龙藏体、志莽行书；后者包含思源黑体和思源宋体的简体中文地区版本。两个预览包各自使用前需解压；若只解压前者，思源黑体和思源宋体会提示文件缺失。

预览页面的字体加载受浏览器本地文件策略影响；字体安装和实际预览可在系统字体工具或剪辑软件中完成。单个字体双击安装，在软件中选择对应字体即可；安装名称和粗细以文件自身显示为准。中文字体并非包含所有汉字，遇到生僻字应检查字形。
